# 产品知识库 RAG 问答系统（完整版 · 含语义模型）

## 启动新版

按照 [PostgreSQL + Chroma 启动与旧库迁移](README.md#postgresql--chroma-启动与旧库迁移) 配置 PostgreSQL、Chroma 和 Embedding。项目原文、会话和评测记录保存在 PostgreSQL，查询向量由 Embedding 模型生成并交给 Chroma 检索。

配置好 `.env` 后双击 `start_mac.command` 或 `启动.bat`。需要本地 PostgreSQL 或 Chroma 时请先打开 Docker Desktop。Chroma 配置留空时，脚本会启动本地 Chroma，并在连接检查通过后自动保存配置。

首次切换时，启动新版并打开「知识配置 → 旧库迁移」，点击「一键迁移旧库」。默认读取 `data/rag.sqlite3`，也可以在启动前用 `RAG_LEGACY_DB` 指定文件。

也可以在配置好环境变量的终端运行：

```bash
python run_server.py --migrate-sqlite data/rag.sqlite3
```

需要导入内置语料时，可把命令里的文件换成 `data/sms.sqlite3`。迁移成功后，使用 `python run_server.py` 启动并打开终端显示的地址。

## 关于大模型

**本包不含任何 API 密钥**（课程要求禁止把真实密钥打进代码包）。
默认是「检索 + 原文回退」模式。使用 Chroma Cloud 时需要网络，离线查询需要已缓存的本地 Embedding 模型和可访问的自管 Chroma 服务。

要启用大模型生成，在「知识配置 → 免费 API 与模型选择」填自己的 Key：

| 字段 | 推荐值 |
|---|---|
| 服务商 | 自定义兼容 API |
| Base URL | https://open.bigmodel.cn/api/paas/v4 |
| 模型 | glm-4-flash |

## 旧版历史评测（供老师参考）

- 字符检索：Hit@1 **79.0%**、Hit@3 92.8%、状态准确率 97.5%、拒答正确率 80%
- 语义检索 + 大模型：Hit@1 48.6%、误答率 60%（**低于字符检索**）
- 原因：语料为「一行一事实」的短片段（平均 34 字），语义模型缺乏上下文；
  且产品名是最有效的区分信号，语义向量把它当噪声
- 详细数据见 `评估报告/RAG评估与数据分析报告_v3.docx`
