# 产品知识库 RAG 问答系统（完整版 · 含语义模型）

## 这个包和精简版的区别

| | 精简版（4.6 MB） | 完整版（本包，约 500 MB） |
|---|---|---|
| 代码 + 语料 + 数据库 | ✅ | ✅ |
| 语义检索模型 | ❌ 需自行下载 | ✅ **已内置，可离线** |
| 评估报告与图表 | 部分 | ✅ 全部 |
| 离线可用 | 字符检索模式可用 | **全功能离线可用** |

## 三步跑起来

```
1. 解压（约 500 MB，需保证磁盘空间 ≥ 1.5 GB）
2. 双击  启动.bat
3. 浏览器打开终端打印的地址（通常 http://127.0.0.1:8000）
```

首次启动会自动：建虚拟环境 → 装基础依赖 → 装语义依赖（torch/faiss，约 250 MB，需联网）→ 启动。

**注意**：语义检索依赖必须联网安装一次。如果只想快速看效果、不想装 250 MB 依赖，
可以把 `启动.bat` 里的 `set RAG_RETRIEVER=semantic` 改成 `hash`，这样只装基础依赖（约 2 分钟）。

## 关于大模型

**本包不含任何 API 密钥**（课程要求禁止把真实密钥打进代码包）。
默认是「检索 + 原文回退」模式，不联网也能答。

要启用大模型生成，在「知识配置 → 免费 API 与模型选择」填自己的 Key：

| 字段 | 推荐值 |
|---|---|
| 服务商 | 自定义兼容 API |
| Base URL | https://open.bigmodel.cn/api/paas/v4 |
| 模型 | glm-4-flash |


## 实测结论（供老师参考）

- 字符检索：Hit@1 **79.0%**、Hit@3 92.8%、状态准确率 97.5%、拒答正确率 80%
- 语义检索 + 大模型：Hit@1 48.6%、误答率 60%（**低于字符检索**）
- 原因：语料为「一行一事实」的短片段（平均 34 字），语义模型缺乏上下文；
  且产品名是最有效的区分信号，语义向量把它当噪声
- 详细数据见 `评估报告/RAG评估与数据分析报告_v3.docx`
