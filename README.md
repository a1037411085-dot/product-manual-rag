# 产品说明书智能问答系统

期中项目资料：代码、五份产品说明书、SQLite 数据库、评估报告、期中汇报及演示动画。

## 下载

在仓库页面点击 **Code → Download ZIP**，解压后使用；协作开发可用 `git clone` 下载。

## Windows 运行

安装 Python 3.9 或以上，连接网络。进入 `ai-rag-product-完整版/ai-rag-product-完整版`，在该目录打开 PowerShell，依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:RAG_DB = (Resolve-Path data\sms.sqlite3).Path
$env:RAG_RETRIEVER = "hash"
$env:RAG_ANSWER_MODE = "extractive"
.\.venv\Scripts\python.exe run_server.py
```

浏览器打开终端显示的地址，通常是 http://127.0.0.1:8000/。保持终端开启；关闭终端即停止服务。现成数据库是演示快照，会随着本机问答产生新记录；不要直接将本机测试数据推送覆盖共享数据库。原 `启动.bat` 使用语义模式并需要模型缓存，首次使用请优先按上述字符检索步骤运行。

## 老师提出的问题与后续升级

1. 寻找适合产品说明书问答的公开标准数据集，核实授权、语种、任务及是否有证据标注；构建与现有说明书同口径的测试子集，记录筛选依据和数据版本。
2. 建立可靠评估：划分开发集与独立测试集，标注参考答案和证据，衡量检索命中率、回答正确性和证据忠实度，同时评估拒答、转人工、延迟和典型失败案例。针对模型、检索和切片分别做控制变量对照，结合人工复核。

以上是后续研究方向，不代表标准数据集或升级已经完成。

## 协作与安全

组员修改前先拉取最新版本，建议各自使用分支提交并通过 Pull Request 合并。模型 API 密钥不得提交；每个人在本机配置自己的 Key。数据库为历史演示快照，不含模型配置密钥文件；数据库可能包含演示问答与转人工记录。服务无鉴权，仅限本机演示，不要直接暴露公网。
